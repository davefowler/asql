# Change Log

All notable changes to the ASQL VS Code extension will be documented in this file.

## [0.1.0] - 2025-01-XX

### Added
- Initial release of ASQL VS Code extension
- Syntax highlighting for ASQL language
- TextMate grammar for ASQL syntax
- Code snippets for common ASQL patterns
- Language configuration (comments, brackets, auto-closing)
- Indentation support for pipeline syntax
- File association for `.asql` files

### Features
- Highlighting for keywords, operators, functions, and literals
- Support for all ASQL pipeline operators (`from`, `where`, `group by`, `order by`, `limit`, etc.)
- Snippets for quick query creation
- Smart indentation for multi-line queries
