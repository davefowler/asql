# Feature status (canonical pointers)

We previously had multiple “feature status” documents that drifted and contradicted the implementation.

Canonical sources now:

- **Current language spec (what exists / how it works)**: `docs/spec.md`
- **Not implemented yet**: tracked as GitHub issues when prioritized
- **Future/maybe ideas (design-only)**: `docs/spec_future.md`

For the most reliable answer to “is X implemented?”, check the tests in `tests/`.
