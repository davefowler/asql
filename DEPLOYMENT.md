# Deployment Setup Summary

This project is configured to deploy:
- **Docs**: Netlify (static site from MkDocs)
- **Playground**: Railway (Flask application)

## Quick Start

### 1. Deploy Playground to Railway

1. Go to https://railway.app and create a new project
2. Connect your GitHub repository
3. Railway will automatically detect:
   - `Procfile` → runs `python playground.py`
   - `requirements.txt` → installs dependencies
4. Railway will provide a public URL (e.g., `https://asql-playground-production.up.railway.app`)

See [RAILWAY.md](RAILWAY.md) for detailed Railway setup instructions.

### 2. Update Netlify Configuration

After deploying to Railway, update `netlify.toml` with your Railway playground URL:

```toml
[build.environment]
  PLAYGROUND_URL = "https://your-actual-railway-url.railway.app"
```

### 3. Deploy Docs to Netlify

1. Go to https://app.netlify.com
2. Connect your GitHub repository
3. Netlify will automatically:
   - Run the build command: `pip install -r requirements-docs.txt && python scripts/prepare_docs.py && mkdocs build`
   - Replace playground URLs in docs with your Railway URL
   - Deploy the static site

## How It Works

### Railway (Playground)

- **Entry Point**: `Procfile` → `web: python playground.py`
- **Dependencies**: `requirements.txt` (flask, sqlglot)
- **Port**: Automatically set by Railway via `PORT` environment variable
- **URL**: Provided by Railway (or custom domain if configured)

### Netlify (Docs)

- **Build Command**: Installs dependencies, runs `prepare_docs.py` to replace playground URLs, then builds MkDocs
- **Publish Directory**: `site/` (generated by MkDocs)
- **Playground URL**: Set via `PLAYGROUND_URL` environment variable in `netlify.toml`

### URL Replacement

The `scripts/prepare_docs.py` script replaces:
- `src="/playground/embed"` → `src="{PLAYGROUND_URL}/embed"`
- `href="/playground"` → `href="{PLAYGROUND_URL}"`

This ensures docs on Netlify point to the playground on Railway.

## Troubleshooting

### Playground not accessible from docs
- Verify `PLAYGROUND_URL` in `netlify.toml` matches your Railway URL
- Check Railway logs to ensure playground is running
- Verify CORS settings if needed

### Docs build fails
- Check that `scripts/prepare_docs.py` is executable
- Verify `PLAYGROUND_URL` is set in `netlify.toml`
- Check Netlify build logs for errors

### Railway deployment fails
- Verify `Procfile` and `requirements.txt` are in the root directory
- Check Railway logs for dependency installation errors
- Ensure `PORT` environment variable is being set (Railway does this automatically)
